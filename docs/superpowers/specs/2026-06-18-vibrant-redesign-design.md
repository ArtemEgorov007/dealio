# Редизайн Dealio в стиле Vercel

> Эта версия спеки заменяет первоначальное направление "Vibrant" (градиентные заливки) — после ревью оно показалось устаревшим («стиль 2017»). Финальное направление — строгая монохромная эстетика в духе Vercel/Linear-дашбордов, применённая на всё приложение, а не только на доску.

## Контекст

Исходный UI — светлый «премиальный SaaS» (акцент teal `#0d9488`, Manrope, белые карточки). Прошли через 3 раунда брейнсторма:
1. Выбор характера (Editorial / Warm minimal / Vibrant) → выбран Vibrant.
2. Ревью показало, что градиентные заливки карточек читаются как дизайн 2016–2018 → пересмотрено в сторону сдержанного 2025-стиля, затем уточнено до конкретно Vercel-эстетики.
3. Композиция доски (равные карточки-блоки → плотные строки), метрики (карточки → текстовая строка → пилюли-чипы — финальный вариант).

## Цветовая и визуальная система

- **Фон**: чистый чёрный (`#000`), sidebar и контент в одном тоне, разделены тонкой границей `#1f1f1f`.
- **Шрифт**: Inter (close-аналог Geist, который использует сам Vercel; уже есть `@nuxtjs/google-fonts` в проекте — заменить текущий `Manrope` на `Inter`). Числа/цены — моноширинный шрифт (`font-family: monospace` или подключить `Roboto Mono` / `JetBrains Mono` через тот же модуль).
- **Границы вместо заливок**: никаких градиентных фонов на карточках. Базовый токен карточки/строки: `background:#0a0a0a; border:1px solid #1f1f1f; border-radius:8px`.
- **Цвет типа элемента** передаётся только двумя способами:
  - маленькая точка-индикатор (6px circle) справа в строке задачи/идеи;
  - узкая 3px-полоска слева у карточек, где она уместна (не используется в финальной плотной композиции колонок — там только точка).
  - Палитра точек: Идеи `#4facfe`, Задачи `#a78bfa`, В работе `#ff9a44`, Готово `#34e89e`, Wishlist — без точки, вместо неё сумма (см. ниже).
- **Кнопки**: первичная кнопка — белый фон, чёрный текст, `border-radius:6px` (как у Vercel `+ Добавить`, `Войти`).
- **Денежные суммы**: только число, **без значка ₽** (ни в строках Wishlist, ни в метрике, ни где-либо ещё в новом дизайне).

## Композиция доски (`/`)

Заменяется текущая раскладка «карточка-блок на всю ширину колонки» на **плотные строки** (Linear-style):
- Заголовок колонки: название + счётчик количества справа, без иконок Lucide (от иконок в заголовках колонок отказались в пользу точки-индикатора внутри строки — см. палитру выше).
- Каждый элемент — строка `.vrow`: тёмный фон, граница, первая/последняя строка колонки скруглены (контейнер выглядит как единый список), название слева, точка-индикатор (или сумма для Wishlist) справа.
- Под последней строкой — пунктирная кнопка `+ Добавить`.
- Колонки в горизонтальный скролл-ряд, как сейчас, ширина ~220px.
- **Метрики сверху** (Всего / В работе / Готово / Wishlist) — компактные пилюли-чипы в одну строку под заголовком "Мой трекер" (`border:1px solid #222; border-radius:999px; padding:5px 12px`), с маленькой цветной точкой слева от подписи и числом, выделенным белым/bold. Никаких боксов-карточек метрик.

## Sidebar

Перекрашивается в тёмный, в один тон с фоном (`#000`/`#0a0a0c`), активный пункт — `background:#111`, без градиентной плашки. Переключатель темы убирается полностью (`ThemeToggle.vue` и все его использования удаляются) — приложение становится **только тёмным**.

## Логин (`/login`)

Сейчас светлая карточка на градиентном фоне. Меняется на: чёрный фон, центр экрана, тот же `D`-логотип (белый квадрат/чёрная буква), инпуты `background:#0a0a0a; border:1px solid #2a2a2a`, кнопка «Войти» — белая с чёрным текстом, «Демо-режим» — обводка вместо текущего варианта.

## Заглушки "в разработке" (`UnderDevelopment.vue`, используется в dashboard/help/ideas/tasks/wishlist)

Чёрный фон, иконка в карточке `48×48` с тонкой границей вместо текущего блюр-фрост эффекта, нейтральный серый текст. Контент и условие показа не меняются.

## Архив и Настройки (`archive.vue`, `settings.vue`)

Эти страницы — рабочие (countdown/restore, retention-настройки). Визуально приводятся к тем же базовым токенам (`.vrow`/карточка с границей, белые первичные кнопки, инпуты как на логине) — без отдельного мокапа, по аналогии с уже утверждённым стилем.

## Иконки

Lucide через `@nuxt/icon` (`i-lucide-*`) используется точечно — там, где в финальной композиции остались иконки (заглушка "в разработке": иконка `alert-circle` или похожая; возможно кнопки в Архиве/Настройках). В заголовках колонок доски и в шапке трекера иконки **не используются** — цвет передаёт точка-индикатор.

## Затронутые файлы

- `app/components/kanban/KanbanCard.vue` → пересобирается в `.vrow`-строку (или переименовать/заменить на новый компонент строки, если структура далеко уходит от "карточки").
- `app/components/kanban/KanbanColumn.vue` — рендер списком строк + пунктирная кнопка добавления, без иконки в заголовке.
- `app/components/kanban/KanbanStats.vue` — заменяется на ряд пилюль-чипов.
- `app/components/layout/Sidebar.vue`, `app/components/layout/menu.data.ts` — тёмный фон, активный пункт без градиента.
- `app/components/ui/ThemeToggle.vue` и все его использования — удаляются.
- `app/pages/login.vue` — новая чёрная компоновка.
- `app/components/ui/UnderDevelopment.vue` — чёрный фон, иконка с границей вместо frost-эффекта.
- `app/pages/archive.vue`, `app/pages/settings.vue` — обновление визуальных токенов (см. выше), без изменения логики.
- `nuxt.config.ts` (`@nuxtjs/google-fonts` секция) — `Manrope` → `Inter` (+ моноширинный шрифт для чисел).
- Глобальные CSS-токены (`app/assets/css/variables.css`, `dark-theme.css`, `kanban-effects.css`) — обновить цветовые переменные на новую палитру; `kanban-effects.css` скорее всего придётся пересмотреть полностью (текущие эффекты заточены под карточки-блоки, не под строки).

## Что не меняется

- Data-слой (Pinia `store/board.store.ts`, Appwrite-вызовы, гостевой режим, `kanban.mock.ts`) — только визуальный слой.
- Структура страниц/роутинг.
- Известные TS-ошибки в `app/pages/orders.vue`/`settings.vue` — вне скоупа (эти страницы — заглушки `UnderDevelopment`, кроме `settings.vue`, который рабочий, но ошибки там не трогаем).

## Критерии готовности

- Везде в приложении (доска, логин, заглушки, архив, настройки, sidebar) — чёрный фон, нет градиентных заливок, нет переключателя тёмной/светлой темы.
- Доска отображается списком плотных строк по колонкам, с пилюлями-метриками сверху.
- Денежные суммы везде без значка ₽.
- Шрифт — Inter (замена Manrope), числа — моноширинным шрифтом.
- Сборка (`npm run build`, GitHub Actions `nuxtjs.yml`) проходит без новых ошибок.
