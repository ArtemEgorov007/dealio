# Редизайн Dealio в стиле Vibrant

## Контекст

Текущий UI — светлый «премиальный SaaS» (акцент teal `#0d9488`, Manrope, белые карточки). Нужен полный визуальный редизайн с новым характером: тёмный фон, яркие градиентные акценты по типу элемента, более крупные и весомые карточки, иконки вместо эмодзи.

Направление выбрано в брейнсторме (3 варианта на выбор: Editorial, Warm minimal, Vibrant) — победил **Vibrant** с явным перевесом голосов.

## Цветовая и визуальная система

- **Фон страницы и sidebar**: тёмный, единый тон (`#0b0a12` / `#13111c`), без переключателя тем — светлая тема убирается.
- **Карточки колонок и сами kanban-колонки**: тёмно-фиолетовый фон-контейнер (`#171626`), внутри — градиентная карточка по типу:
  - Идеи — голубой градиент (`#4facfe → #00c2ff`)
  - Задачи — фиолетовый (`#a78bfa → #7c5cff`)
  - В работе — оранжево-розовый (`#ff9a44 → #ff6b6b`)
  - Готово — зелёный (`#34e89e → #0f3443`)
  - Wishlist — розово-фиолетовый (`#ff6b9d → #c44dff`)
- **Карточки крупнее текущих**: ширина колонки ~230–260px (сейчас уже близко), внутренний padding увеличен (16–18px), заголовок карточки 15–16px/700, добавлена круглая icon-badge (`rgba(255,255,255,0.22)` фон, белая line-иконка) как визуальный якорь сверху карточки.
- **Без текстовых бейджей типа на карточке** («ИДЕЯ»/«ЗАДАЧА»/«WISHLIST» убираются) — тип уже виден по заголовку колонки и цвету градиента. На карточке остаётся: заголовок + (для wishlist) цена + дата с маленькой иконкой часов.
- **Метрики сверху** (Всего / В работе / Готово / Wishlist ₽) — нейтральные тёмно-серые карточки (`#171626` фон, иконка в плашке `#23213a`), не градиентные — чтобы не спорить по цвету с kanban-колонками.
- **Sidebar**: перекрашивается в тёмный, в один тон с фоном доски (`#13111c`), активный пункт меню — градиентная плашка (розовый→фиолетовый).

## Иконки

Эмодзи в заголовках колонок (💡✅⚡🎉🎁) заменяются на line-иконки из набора **Lucide** через уже подключённый `@nuxt/icon` (зависимость в `package.json`, см. `nuxt.config.ts`) — формат `i-lucide-*`, никаких новых npm-зависимостей.

Соответствие:

- Идеи → `lightbulb`
- Задачи → `clipboard-list`
- В работе → `zap`
- Готово → `check-circle-2`
- Wishlist → `gift`
- Дата на карточке → `clock` (маленький размер, рядом с текстом даты)

- `app/components/ui/ThemeToggle.vue` и все его использования (sidebar) — удаляются полностью, компонент больше не нужен.

## Что не меняется

- Data-слой (Pinia store `store/board.store.ts`, Appwrite-вызовы, гостевой режим) — не трогаем, только визуальный слой.
- Структура страниц/роутинг — без изменений.
- Известные TS-ошибки в `app/pages/orders.vue` и `settings.vue` — вне скоупа (эти страницы — `UnderDevelopment.vue`, не затрагиваются редизайном).

## Критерии готовности

- На доске (демо-режим, `/`) визуально: тёмный фон везде (sidebar + контент), кириллица читаема на градиентах (контраст белого текста на градиентных карточках проверить вручную через скриншот), иконки Lucide вместо эмодзи во всех 5 колонках, без текстовых бейджей типа на карточках.
- Переключателя светлой/тёмной темы нет в интерфейсе.
- Сборка (`npm run build` / текущий GitHub Actions workflow `nuxtjs.yml`) проходит без новых ошибок.
